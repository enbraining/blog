# 해시 함수란?

해시 함수는 입력된 값에 대한 고유한 식별자를 만들어서 출력하는 함수를 말합니다.

이러한 식별자는 입력된 값의 길이와 상관없이 항상 동일한 길이의 출력 값을 계산해내는데 이로 인해 발생하는 문제가 있습니다.

```
hello                -> 11p3orgng19hg1rg1gpiu1ggh1gj
why are you serious? -> asdfouhaivsnkdla2rv3h2vjohi2
```

바로 입력 값이 가질 수 있는 경우의 수보다 출력 값이 가지는 경우의 수가 훨씬 적다는 것입니다.

그렇기에 어떤 입력 값들은 서로 동일한 출력 값이 발생하는 충돌 현상이 일어날 수 밖에 없습니다.

이는 고정된 길이의 출력 값을 출력하는 해시 함수의 특성상 SHA-2, SHA-3 등 어떤 알고리즘을 써도 해결이 불가합니다.

하지만 길이를 늘려서 충돌이 발생할 확률을 낮출 수는 있겠죠?

보편적으로 암호 알고리즘은 128비트 이상의 복잡도를 가질 것을 권장합니다.

그럼 왜 SHA-128이 아니라 SHA-256 알고리즘을 쓰는 걸까요?

## 비둘기 집의 원리

위 사진을 보면 비둘기가 각자 한칸씩 차지하고 있는 모습을 확인할 수 있습니다.

운이 좋다면 한칸씩 차지하는 경우의 수도 있겠지만, 통계적으로는 전체 칸 수의 제곱근(√n) 정도만 시도한 시점부터 똑같은 칸에 비둘기가 들어갈 확률이 급격히 높아지게 됩니다. 절반이 아니라 제곱근이라는 점이 핵심입니다.

SHA-256도 이와 비슷하게 2의 256제곱(256비트) 개의 모든 경우의 수를 다 시도하지 않더라도, 2의 128제곱(128비트) 개의 경우의 수를 시도한 이후부터는 충돌이 발생할 확률이 기하급수적으로 올라갑니다.

> 정확히는 2의 2분의 n 제곱 개 경우의 수를 시도한 이후부터 충돌 확률이 기하급수적으로 상승합니다. (n은 비트 길이)

위 시뮬레이션은 SHA-256 출력을 12비트로 잘라낸 것이지만, 잘라낸 길이가 몇 비트든 생일 문제의 한계는 그대로입니다. 12비트면 2^6, 256비트면 2^128번째 시도 부근에서 충돌 확률이 치솟습니다.

여기서 해시 함수가 가져야할 성질 중 한가지를 찾아볼 수 있습니다. 바로 충돌 저항성입니다.

충돌 저항성이란, 공격자가 임의의 두 입력값에 대한 해시를 구했을 때 동일한 값이 나올 수 없다는 성질입니다. (수학적으로 불가능한 것이 아니라 현실적으로 불가능한 것을 말합니다.)

이와 비슷하지만 입력 x에 대한 해시 값 y가 존재할 때, 다른 입력에 대해 동일한 y가 나올 수 없는 것을 제2 역상 저항성이라고 합니다.

마지막 세번째로 입력 값에 대한 해시 값을 구할 수는 있지만, 반대로 해시 값으로 원본 입력값을 찾아낼 수 없는 것을 역상 저항성이라고 합니다.

- 역상 저항성: 해시 함수에 대한 역함수는 없음
- 제2 역상 저항성: 입력 값에 대한 해시 값이 존재할 때, 이와 동일한 해시 값을 만들어내는 다른 입력값은 없음
- 충돌 저항성: 임의의 두 입력값에 대해 해시 값이 동일할 수 없음
