# 해시 함수란?

해시 함수는 입력된 값에 대한 고유한 식별자를 만들어서 출력하는 함수를 말합니다.

이러한 식별자는 입력된 값의 길이와 상관없이 항상 동일한 길이의 출력 값을 계산해내는데 이로 인해 발생하는 문제가 있습니다.

```
hello                -> 11p3orgng19hg1rg1gpiu1ggh1gj
why are you serious? -> asdfouhaivsnkdla2rv3h2vjohi2
```

바로 입력 값이 가질 수 있는 경우의 수보다 출력 값이 가지는 경우의 수가 훨씬 적다는 것입니다.

그렇기에 어떤 입력 값들은 서로 동일한 출력 값이 발생하는 충돌 현상이 일어날 수 밖에 없습니다.

하지만 길이를 늘려서 충돌이 발생할 확률을 낮출 수는 있겠죠?

보편적으로 암호 알고리즘은 128비트($2^{128}$) 이상의 경우의 수를 가질 것을 권장합니다.

그럼 왜 SHA-128이 아니라 SHA-256 알고리즘을 쓰는 걸까요?

## 생일 경계 문제

생일 경계 문제는 한 집단에서 최소 몇명이 있어야 최소 2명 이상 사람의 생일이 겹칠 가능성이 50% 이상이 될지에 대한 문제입니다.

예를 들어 23명의 사람이 있다고 해봅시다.

A의 생일이 충돌하지 않을 확률은 $\frac{365}{365}$, B의 생일이 A의 생일과 충돌하지 않을 확률은 $\frac{364}{365}$이고, C는 $\frac{363}{365}$일 것입니다.

이런식으로 아래와 같이 마저 계산을 이어나가면 23명이 있을 때 생일이 충돌될 확률은 대략적으로 50% 가까이 나옵니다.

$$
\frac{364}{365} \times \frac{363}{365} \times \cdots \times \frac{343}{365} \approx 0.4927
$$

전체 경우의 수가 n개라고 했을 때, $n^{1/2}$번 시도한 이후부터 충돌 확률은 50% 이상으로 상승합니다.

SHA-256에도 이와 동일하게 적용해보면 $2^{256 \times \frac{1}{2}} = 2^{128}$번 시도한 시점부터 충돌 확률이 급상승합니다.

여기서 해시 함수가 가져야할 성질 중 한가지를 찾아볼 수 있습니다. 바로 충돌 저항성입니다.

충돌 저항성이란, 공격자가 임의의 두 입력값에 대한 해시를 구했을 때 동일한 값이 나올 수 없다는 성질입니다. (수학적으로 불가능한 것이 아니라 현실적으로 불가능한 것을 말합니다.)

이와 비슷하지만 입력 x에 대한 해시 값 y가 존재할 때, 다른 입력에 대해 동일한 y가 나올 수 없는 것을 제2 역상 저항성이라고 합니다.

마지막 세번째로 입력 값에 대한 해시 값을 구할 수는 있지만, 반대로 해시 값으로 원본 입력값을 찾아낼 수 없는 것을 역상 저항성이라고 합니다.

- 역상 저항성: 해시 함수에 대한 역함수는 없음
- 제2 역상 저항성: 입력 값에 대한 해시 값이 존재할 때, 이와 동일한 해시 값을 만들어내는 다른 입력값은 없음
- 충돌 저항성: 임의의 두 입력값에 대해 해시 값이 동일할 수 없음

# 결함이 발견된 함수들

SHA-1은 해당 알고리즘 내에서 사용된 압축 함수 구조에서 수학적 약점이 발견되었습니다.

실제로 구글에서 GPU 클러스터 연산을 통해 다른 입력 값에 대해 동일한 해시 값이 나오는 것을 발견하였습니다.

위와 같이 제2 역상 저항성을 만족하지 못하기에 SHA-1은 더 이상 사용되지 않습니다.

현재는 대부분 SHA-2를 사용하며, 이는 224, 256, 384, 512비트로 이루어진 해시 값을 지원합니다.

- SHA-224
- SHA-256
- SHA-384
- SHA-512
- SHA-512/224
- SHA-512/256
